# Wisdom — Phase 2: Site

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **REQUIRED READING BEFORE STARTING:** [Master plan + frozen contracts](./2026-05-13-wisdom.md). Sections C1, C2, C3, C8, C10 are constraints — do not deviate.
>
> **Worktree:** `../wisdom.p2` on branch `feat/p2-site`. All work happens here.
>
> **Prerequisite:** the bootstrap commit on `main` (made by the dispatcher before fork) provides `wisdoms/_categories.yml`, `.gitignore`, `AGENTS.md`, `CLAUDE.md`, and `LICENSE`. Verify these are present in your worktree before starting (Task B1). If missing, **halt and surface** to the dispatcher — do not invent them.

**Goal:** Stand up a Jekyll-driven GitHub Pages site with neo-brutalist styling, six bucket pages, per-snippet permalinks, tag pages, and Pagefind search. Build via GitHub Actions. Render gracefully when the corpus is empty.

**Architecture:** Drop the `gh-pages-neo-brutalist` templates into the repo root, then add a `_wisdoms` Jekyll collection (sourced from `wisdoms/`), six bucket pages that filter the collection, a `_plugins/tag_pages.rb` generator for `/tags/<tag>/`, a Pagefind step in the existing Pages workflow, and a `/search/` page that mounts the Pagefind UI.

**Tech Stack:** Jekyll (github-pages gem), kramdown, IBM Plex Mono, Pagefind v1, GitHub Actions.

- [ ] **Step 1: Write the page**

```markdown
---
layout: page
title: About
eyebrow: ABOUT
---

This site is a personal collection of wisdom — quotes, observations, and small
arguments worth remembering. It is built from one Markdown file per snippet,
each filed under a closed set of buckets and tagged for cross-cutting concerns.

## Buckets

{% for cat in site.data.wisdoms.categories %}
- **<span class="eyebrow-{{ cat.color }}">{{ cat.label }}</span>** — {{ cat.description }}
{% endfor %}

## How snippets land here

Each snippet is captured via a CLI (`wisdom "..."`) or by typing `/wisdom`
(Claude / Devin) or `$wisdom` (Codex) inside an agent session. An LLM
categorizes the snippet into one of the buckets above, with the option to
propose a new bucket if no existing one fits. The snippet is saved as a
Markdown file with structured frontmatter, then committed and (optionally)
pushed. This site rebuilds automatically on push.

## Search

The [search page](/search/) uses [Pagefind](https://pagefind.app/) — a
client-side full-text search index built from the rendered HTML at deploy
time. Filter by bucket or tag using the filters below the query box.

## Source

The repository, including the CLI, the skill, and the entire corpus, lives at
<https://github.com/amit-t/wisdom>.

## License

Code is MIT; the corpus itself is CC BY 4.0. See `LICENSE` in the repo.
```

## Task B11: `_plugins/tag_pages.rb` — tag page generator

**Files:**
- Create: `_plugins/tag_pages.rb`

Jekyll custom plugins run when the Pages workflow runs `bundle exec jekyll build` from a GitHub Actions runner (not the legacy Pages build, which disables plugins). Since the scaffold's `pages.yml` uses Actions, custom plugins are allowed.

- [ ] **Step 1: Write the generator**

```ruby
# _plugins/tag_pages.rb
# Generates /tags/<tag>/ index pages from the union of all wisdom tags.

module Jekyll
  class TagPage < Page
    def initialize(site, base, dir, tag, tagged)
      @site = site
      @base = base
      @dir  = dir
      @name = 'index.html'

      self.process(@name)
      self.read_yaml(File.join(base, '_layouts'), 'page.html') if File.exist?(File.join(base, '_layouts', 'page.html'))
      self.data['layout']  = 'page'
      self.data['title']   = "##{tag}"
      self.data['eyebrow'] = 'TAG'
      self.data['description'] = "Wisdoms tagged ##{tag}."
      self.data['tag']     = tag
      self.data['tagged']  = tagged.map(&:url)
      self.content = <<~LIQUID
        {% assign tag = page.tag %}
        {% assign wisdoms_tagged = site.wisdoms | where_exp: "w", "w.tags contains tag" | sort: "created_at" | reverse %}

        {% if wisdoms_tagged.size == 0 %}
          <p class="empty-state">No wisdoms with this tag.</p>
        {% else %}
          <p class="bucket-count">{{ wisdoms_tagged.size }} wisdom{% if wisdoms_tagged.size != 1 %}s{% endif %} tagged <code>#{{ tag }}</code></p>
          <div class="wisdom-list">
            {% for w in wisdoms_tagged %}
              {% include wisdom-card.html wisdom=w %}
            {% endfor %}
          </div>
        {% endif %}
      LIQUID
    end
  end

  class TagPageGenerator < Generator
    safe true
    priority :low

    def generate(site)
      wisdoms = site.collections['wisdoms']&.docs || []
      tags = {}
      wisdoms.each do |w|
        (w.data['tags'] || []).each do |t|
          tags[t] ||= []
          tags[t] << w
        end
      end
      tags.each do |tag, list|
        slug = Jekyll::Utils.slugify(tag, mode: 'pretty')
        site.pages << TagPage.new(site, site.source, File.join('tags', slug), slug, list)
      end
    end
  end
end
```

## Task B12: Pages workflow with Pagefind step

**Files:**
- Modify: `.github/workflows/pages.yml`

- [ ] **Step 1: Replace the workflow**

Current scaffold workflow builds Jekyll only. We need to:
1. Build Jekyll into `_site/`
2. Run `npx pagefind --site _site` to add `/pagefind/` index
3. Upload combined `_site/`

```yaml
name: Deploy GitHub Pages

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - id: pages
        uses: actions/configure-pages@v5
      - uses: ruby/setup-ruby@v1
        with:
          ruby-version: "3.2"
          bundler-cache: true
      - name: Build Jekyll
        run: bundle exec jekyll build --baseurl "${{ steps.pages.outputs.base_path }}"
        env:
          JEKYLL_ENV: production
      - uses: actions/setup-node@v4
        with:
          node-version: "20"
      - name: Build Pagefind index
        run: npx -y pagefind@latest --site _site
      - uses: actions/upload-pages-artifact@v3
        with:
          path: _site

  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```
